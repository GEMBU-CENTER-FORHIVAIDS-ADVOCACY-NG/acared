# POST `/api/v1/prescriptions`

**Operation:** `api_v1_prescriptions_store`  
**Auth:** Yes  
**Team header:** Yes  
**Tags:** prescriptions

## Summary
api.v1.prescriptions.store

## Parameters
| Name | In | Required | Type | Description |
|---|---|---:|---|---|
| `X-Team-Slug` | header | no | `string` | Team slug. Provide this or X-Team-ID for team-scoped endpoints. |
| `X-Team-ID` | header | no | `integer` | Team ID. Provide this or X-Team-Slug for team-scoped endpoints. |

## Request Body
Required: yes

`PrescriptionStoreRequest`

| Field | Type | Required | Description |
|---|---|---:|---|
| `patient_id` | `string` | yes |  |
| `lines` | `array` | yes |  |

### Example
```json
{
  "patient_id": "PAT-001",
  "lines": [
    {
      "price_list_id": 4,
      "quantity": 2,
      "dosage": 1,
      "frequency": 2,
      "duration": 5,
      "comment": "After meal"
    }
  ]
}
```
